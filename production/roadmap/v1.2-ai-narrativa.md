**Window**: 2027-05-01 → 2027-08-31 (~17 weeks · 3-4 months)
**Status**: Planned
**Owner**: Pablo (solo dev)
**Prev**: v1.1 shipped + unlock criteria PASS
**Next**: v1.3 live-ops cadence

Implementa el Pillar D (IA Narrativa Local) que estaba deferred en MVP.
Por primera vez, prensa, rumores y llamadas de alcaldes son texto generado
en runtime, no templates fijos. Stack: llama.cpp server-side.

---

## 1. Goal

> *"Una IA local genera la voz del mundo (prensa, rumores, llamadas) —
> texto vivo, no scripts"* — game-concept.md §Unique Hook.

Al cierre de v1.2:

- llama.cpp corre como sidecar al API process (mismo host o gRPC sidecar).
- Staff messages tier 3 (los más narrativos) son AI-generated.
- Press articles tras partidos clave son AI-generated.
- Llamadas de alcaldes (manager-RPG career progression) son AI-generated.
- Fallback graceful: si AI down, templates de v1.0 siguen funcionando.
- AI safety review: filtros contra output racista/sexista/violento.

## 6. Tech stack additions

| Component | Choice | Reason |
|-----------|--------|--------|
| Model | Llama 3 8B Q4 (or Mistral 7B Q4) | Balance calidad / latencia / VRAM |
| Inference engine | llama.cpp (HTTP server mode) | C++ nativo, gRPC opcional, no Python overhead |
| Hosting | Same host as API (single VM, GPU optional) o sidecar container | Cost-aware, evitar egress |
| Cache | Redis para outputs idénticos (key = hash de prompt context) | Reduce cost en eventos repetitivos |
| Audit | Tabla `ai_outputs` con muestreo 1% para audit manual | GDPR-safe (sin PII) |

---

## 7. Cost & latency model

Asumiendo modelo 8B-Q4 en CPU consumer (M2 / Ryzen 7) sin GPU:

| Operación | p95 latency target | Cost/call (cloud equiv) |
|-----------|-------------------|------------------------|
| Staff message T3 (~200 tokens) | < 2s | ~$0.0001 self-hosted, ~$0.001 OpenAI |
| Press article (~500 tokens) | < 5s | ~$0.0003 / ~$0.003 |
| Mayor call dialogue (~800 tokens) | < 8s | ~$0.0005 / ~$0.005 |

Self-hosted con llama.cpp: cost por usuario activo / mes estimado < $1
asumiendo:
- 50 mensajes T3 / sesión
- 5 sesiones / semana
- 4 partidos derby / mes
- 1 mayor call / mes

vs OpenAI API: ~$5-10 / user / mo → no viable a baja monetización MVP.
**Decisión**: self-host es lock-in vs OpenAI.

ADR-018 documenta la decisión final tras spike.

## 8. Risks

| Riesgo | Probabilidad | Impacto | Mitigación |
|--------|-------------|---------|------------|
| Modelo 8B no produce calidad suficiente | Media | Alta | Fallback a templates documentado. Spike Sprint 29 testea calidad antes de comprometerse. Opción de subir a 13B si hardware tolera. |
| Latencia > 3s en hardware target | Media | Alta | Quantización Q4 ya elegida (más rápido). Si falla, cap a Q5 o reducir max_tokens. Cache agresivo. |
| Output tóxico (racismo/violencia) | Alta | Crítica | Filtro pre-output + sample audit + safety review pre-launch. Si el filter detecta > 1% tóxico, halt AI features hasta fix. |
| Cost overflow self-hosted | Baja | Media | Hosting cost cap definido en ADR-018. Si excede, downgrade modelo o aumentar cache. |
| llama.cpp upgrade breaks API | Media | Media | Pinear version en ADR-018. Update sólo en sprints dedicados. |
| AI puede generar texto en idioma incorrecto (modelos sesgados a inglés) | Media | Alta | Prompts en español explícito + few-shot examples ES + filtro language-detect en safety pipeline. |
| Cost per call mide diferente con scaling | Alta | Media | Métricas observables día 1 de v1.2 → tuning continuo. |

- ❌ Multi-modal (imágenes generadas) — solo texto en v1.2
- ❌ Fine-tuning del modelo con dataset propio — defer a v1.3 si la calidad base lo justifica
