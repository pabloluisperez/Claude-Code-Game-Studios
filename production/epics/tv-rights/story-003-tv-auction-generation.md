**ADR Decision Summary**: `tv_auction` is a STOP event generated by `season_start`. Unlock rules are pure computation given manager/division state. `TVAuctionPayload` extends ADR-015 `EventDecisionPayload` union. `advance()` is blocked while `tv_auction` has `consumed=false`.

**Engine**: Web stack | **Risk**: LOW
**Engine Notes**: STOP events halt advance() until consumed=true (ADR-008 pattern). TVAuctionPayload must be JSON-serialisable (no Map, no class instances — control manifest cross-cutting rule).

**Control Manifest Rules (Feature layer)**:
- Required: Event-system writes WorldState only via cascade decisions parameter (ADR-008) — tv_auction itself does not write WorldState; only the resolution (signing/rejecting) does.
- Required: STOP event at week=0 blocks advance() until consumed=true.
- Forbidden: Hardcoded channel names in DB — only tier + rate stored (OQ-TV-01 resolution).

## Implementation Notes

*Derived from GDD Core Rule 2 + ADR-019 §8 (TVAuctionPayload):*

Location: `apps/api/src/modules/tv-rights/tv-auction-generator.ts`

```typescript
export function generateTVAuctionOffers(
  prevSeasonFinalPosition: number | null,
  currentDivision: 'D1' | 'D2',
  managerReputation: number,
  corruptionExposure: number,
): TVTier[] {
  const offers: TVTier[] = ['LOCAL']

  // T1: only LOCAL
  if (prevSeasonFinalPosition === null) return offers

  const corruptionBlocked = corruptionExposure >= TV_SCANDAL_THRESHOLD  // 60
  if (corruptionBlocked) return offers

  // REGIONAL unlock: D2 pos≤10 OR rep≥2 OR D1 actual
  if (
    (currentDivision === 'D2' && prevSeasonFinalPosition <= REGIONAL_MIN_POSITION) ||
    managerReputation >= 2 ||
    currentDivision === 'D1'
  ) {
    offers.push('REGIONAL')
  }

  // NACIONAL unlock: D1 actual OR rep≥4
  if (currentDivision === 'D1' || managerReputation >= 4) {
    offers.push('NACIONAL')
  }

  return offers
}
```

The `TVAuctionPayload` (ADR-019 §8 / ADR-015 union extension) includes:
- `type: 'tv_auction'`
- `offers` array with `durationOptions` per tier (including `riskFlag` for ⚠️)
- `defaultOption: { tier: 'LOCAL', durationSeasons: 1 }` (timeout → LOCAL 1yr)

`riskFlag` logic (computed at generation):
- `REGIONAL_2YR`: set if `corruptionExposure >= 22` (when REGIONAL is in offers)
- `NACIONAL_3YR`: set if `corruptionExposure > 0` (when NACIONAL is in offers)

The event is inserted into `calendar_events` at season_start with `type='tv_auction'`, `consumed=false`. The partial UNIQUE index (Story 001) prevents duplicate events.

## QA Test Cases

*Logic — pure unit tests for generateTVAuctionOffers; integration test for STOP event blocking.*

- **AC-TV-01/06**: Baseline offer set
  - Given: prev_pos=15, D2, rep=1, corruption=0 (T2+)
  - When: generateTVAuctionOffers(15, 'D2', 1, 0)
  - Then: returns ['LOCAL'] only (no REGIONAL or NACIONAL)

- **AC-TV-02**: REGIONAL via position
  - Given: prev_pos=10, D2, rep=1, corruption=0
  - When: generateTVAuctionOffers(10, 'D2', 1, 0)
  - Then: includes 'REGIONAL'

- **AC-TV-04/49**: D1 → REGIONAL + NACIONAL via D1 actual
  - Given: prev_pos=5, D1, rep=1, corruption=0
  - When: generateTVAuctionOffers(5, 'D1', 1, 0)
  - Then: returns ['LOCAL', 'REGIONAL', 'NACIONAL'] (length 3)

- **AC-TV-12**: T1 = only LOCAL

  - When: generateTVAuctionOffers(null, 'D1', 5, 0)
  - Then: returns ['LOCAL'] only

- **AC-TV-31**: corruption block
  - Given: corruption=60, D1, rep=5, prev_pos=1
  - When: generateTVAuctionOffers(1, 'D1', 5, 60)
  - Then: returns ['LOCAL'] only

- **AC-TV-19**: STOP event blocks advance (integration)
  - Given: season_start generates tv_auction event with consumed=false
  - When: POST /api/game/advance
  - Then: HTTP 409 with blocked:true, reason:pending_stop_event
