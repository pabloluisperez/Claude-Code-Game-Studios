Pablo is a senior/professional developer and creative director on Cascada FC. He communicates in Spanish and expects responses in Spanish.

He uses the ux-designer agent primarily for adversarial gap analysis ("encuentra los problemas") rather than validation of existing design. Prefers direct, structured reports with clear severity labels (BLOCKING / WARNING) tied to concrete implementation consequences.

Game pillar awareness matters to him: every UX recommendation should be checked against P4 (Calm Is The Tempo) — no urgency anxiety, no FOMO patterns. Pilar 1 (Tinkering Beats Optimization) constrains what information the UI reveals.
